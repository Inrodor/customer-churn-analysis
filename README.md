# Customer Churn Analysis & Prediction

## 📌 Overview
This project analyzes customer churn behavior in a telecom dataset and builds a predictive model to identify customers at risk of leaving.

The project demonstrates an end-to-end data analytics workflow, including data cleaning, exploratory analysis, machine learning, and business insights.

---

## 📊 Problem Statement
Customer churn is a major challenge for subscription-based businesses. Identifying customers likely to leave allows companies to take proactive retention measures.

---

## ⚙️ Approach
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature encoding
- Machine learning model (Random Forest)
- Feature importance analysis

---

## 📈 Key Insights
- Month-to-month contracts show significantly higher churn
- Customers with higher monthly charges are more likely to churn
- Customers with low tenure are at higher risk of leaving

---

## 🤖 Model
- Model Used: Random Forest Classifier
- Goal: Predict customer churn (binary classification)

---

## 🛠️ Tools Used
- Python (Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib)

---

## 🚀 Outcome
Developed a predictive model and generated actionable insights to help improve customer retention strategies.
